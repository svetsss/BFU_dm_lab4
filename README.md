## Описание проекта

Проект предназначен для выполнения лабораторной работы по анализу и кодированию англоязычного текста.

В работе выполняются три основных этапа:

1. Подготовка входного текста: перевод в lowercase, фильтрация символов, ограничение алфавита до 32 различных символов.
2. Статистический анализ текста: частоты символов, частоты пар символов, энтропия Шеннона, построение кода Хаффмана.
3. Кодирование того же текста алгоритмом LZW и финальное сравнение с равномерным 5-битным кодом и кодом Хаффмана.

## Условие варианта 2

Необходимо подобрать англоязычный текст длиной примерно 12 000 символов. Для удобства все буквы переводятся в строчные, а остальные символы ограничиваются так, чтобы в тексте было не более 32 различных символов.

Далее необходимо:

- провести статистический анализ по частоте букв и пар букв;
- на основе статистик построить коды Хаффмана;
- закодировать текст этими кодами;
- сравнить количество бит с равномерным 5-битным кодом;
- по формуле Шеннона найти количество информации;
- закодировать тот же текст алгоритмом LZW;
- сравнить LZW с равномерным кодом и кодом Хаффмана.

## Назначение файлов

### `data/raw.txt`

Исходный англоязычный текст до обработки.

### `data/text_clean.txt`

Очищенный текст после нормализации. Этот файл создаётся автоматически при запуске `main.py`.

### `normalize.py`

Файл подготовки текста. Выполняет:

- перевод текста в lowercase;
- удаление символов, не входящих в разрешённый алфавит;
- сохранение текста длиной 12 000 символов;
- проверку количества различных символов.

Разрешённый алфавит состоит из 32 символов:

```text
abcdefghijklmnopqrstuvwxyz .,!?;
```

### `huffman.py`

Файл статистического анализа и кодирования Хаффмана. Выполняет:

- подсчёт частот символов;
- подсчёт частот пар символов;
- вычисление энтропии Шеннона;
- построение бинарных кодов Хаффмана;
- вычисление длины текста при кодировании Хаффманом;
- сравнение с равномерным 5-битным кодом.

Результат сохраняется в файл:

```text
data/results/huffman_results.json
```

### `lzw.py`

Файл реализации алгоритма Lempel-Ziv-Welch. Выполняет:

- построение начального словаря по символам текста;
- кодирование текста индексами словаря;
- динамическое добавление новых строк в словарь;
- обратное декодирование для проверки корректности;
- подсчёт битовой длины LZW-кодирования.

Результат сохраняется в файл:

```text
data/results/lzw_results.json
```

### `main.py`

Главный файл запуска. Последовательно выполняет:

- подготовку текста;
- анализ Шеннона и кодирование Хаффмана;
- кодирование LZW;
- сборку итогового сравнения.

Итоговый файл сравнения:

```text
data/results/summary.json
```

## Запуск проекта

Для запуска всей лабораторной работы нужно выполнить команду из папки проекта:

После запуска результаты будут сохранены в папке:

data/results/

## Краткое описание используемых методов

### Равномерный 5-битный код

Так как после нормализации в тексте не более 32 различных символов, каждый символ можно закодировать фиксированным кодом длины 5 бит:

```text
2^5 = 32
```

Поэтому длина равномерного кодирования равна:

```text
L = 5 · N
```

где `N` — количество символов в тексте.

### Энтропия Шеннона

Энтропия показывает среднее количество информации на один символ источника:

```text
H = -sum(p_i · log2(p_i))
```

где `p_i` — вероятность появления символа.

### Код Хаффмана

Код Хаффмана строит префиксный двоичный код переменной длины. Более частые символы получают более короткие коды, а редкие символы — более длинные.

### Алгоритм LZW

Алгоритм LZW строит словарь повторяющихся фрагментов текста. Вместо повторяющихся строк в выходной поток записываются номера строк из словаря.

## Файлы результатов

### `huffman_results.json`

Содержит:

- длину текста;
- размер алфавита;
- частоты символов;
- топ-50 частот пар символов;
- энтропию Шеннона;
- коды Хаффмана;
- битовую длину кодирования Хаффманом.

### `lzw_results.json`

Содержит:

- количество LZW-кодов;
- итоговый размер словаря;
- максимальную битовую ширину кода;
- битовую длину LZW-кодирования;
- результат проверки декодирования.

### `summary.json`

Содержит итоговое сравнение трёх способов кодирования:

| Метод | Что измеряется |
|---|---|
| Равномерный 5-битный код | Базовая длина кодирования |
| Код Хаффмана | Сжатие за счёт частот символов |
| LZW | Сжатие за счёт повторяющихся фрагментов |
